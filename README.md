## ✨ Key Features & Sections

1. **Header & Navigation**:
   - Distinct gold brand logo with letter-spaced `PROPERTY` subtext.
   - Sticky navigation with glassmorphism blur on scroll.
   - Quick "Book a Call" CTA button.
   - Responsive slide-in mobile navigation drawer with animated hamburger toggle.

2. **Hero Section**:
   - Exact typography: *"Buy & Sell Land in Prayagraj with Trust"*.
   - Subtitle with UP RERA registered trust markers.
   - Dual CTA buttons: *"Explore Locations"* and *"Book a Free Call"*.

3. **Performance Stats Strip**:
   - 3-Column layout: `1+` Years of Experience, `100+` Plots Sold, `200+` Happy Clients.
   - Automated JavaScript intersection counter animations.
   - Distinct vertical border dividers (`#59564D`).

4. **About Section**:
   - Showcase image with sleek borders and badge card.
   - Headline: *"Prayagraj's Premier Land Specialists"*.
   - Value propositions (Freehold clear titles, PDA norms, end-to-end registration).
   - Direct link to real estate blogs with gold arrow.

5. **Feature / Partner Banner**:
   - Full-width dark luxury showcase with responsive copy and hero plot image.

6. **Prime Locations Section**:
   - 3-Column responsive card grid (Civil Lines, George Town, Tagore Town).
   - Price & zoning badges, location highlights, and instant exploration triggers.

7. **Market Intelligence & Blogs**:
   - 3 curated articles on Prayagraj land acquisition, UP RERA verification, and emerging growth corridors.

8. **Q&A Accordions (FAQ)**:
   - 6 comprehensive FAQs covering RERA, legal checks, registry timeline, and financing.
   - Smooth expand/collapse animation with gold accent bar on active item.

9. **CTA & Lead Form Section**:
   - Transparent dark inputs with glowing gold focus ring.
   - Real-time client-side Indian phone number validation (`+91` or 10-digits starting 6-9) and email verification.

10. **4-Column Luxury Footer**:
    - Logo, quick links, prime locations, address in Civil Lines Prayagraj, and centered "Book a Call" button.

11. **Modals & Utilities**:
    - Floating scroll-to-top button.
    - Accessible "Book a Call" lead capture modal.
    - Toast feedback notifications upon submission.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve with a local web server:

```bash
# Using VS Code Live Server or Python:
python -m http.server 8000
```
Visit `http://localhost:8000` in your browser.
